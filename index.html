How I work

A beautiful screen that people can’t use is still broken. Every project starts with the people using it, and ends with code that matches the design.

  1. 01

    Understand

    User interviews, personas, journey maps and a heuristic review of what exists today, so we fix the real problem.

  2. 02

    Structure

    Information architecture, task flows and wireframes — tested with users before anything gets polished.

  3. 03

    Design

    High-fidelity UI, prototypes, micro-interactions and design systems that keep growing products consistent.

  4. 04

    Ship

    Accessible, semantic front-end code or developer-ready specs, then design QA so what launches is what we designed.

Research first, pixels second

I’ve been designing for the web since 2005 — long enough to know that the best interface is the one people don’t have to think about.

I’m a UX/UI designer and HFI Certified Usability Architect (CUA)™. I work the full arc: user research, journey mapping and usability evaluation, through information architecture and design systems, to accessible, WCAG-compliant interfaces in production-ready code.

Because I design and build, nothing gets lost between the mockup and the launch. I can write the spec or work from one, and step into Angular, React or Vue codebases when the build drifts from the design.
